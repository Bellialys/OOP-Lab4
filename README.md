# OOP-Lab4

Практичне завдання №4 з дисципліни «Об'єктно-орієнтоване програмування».

Тема: Структури, класи, функції.

## Завдання 1 — магазин

Симуляція магазину розширена, але базові вимоги практичного завдання збережені.

### Асортимент і склад

У магазині 24 позиції з різних категорій: випічка, молочні продукти, фрукти, солодощі, крупи, бакалія, напої, м'ясні продукти та інші продукти.

Кількість кожної позиції генерується випадково від 40 до 250 одиниць при створенні нового магазину.

### Покупці

Для кожного покупця:

- випадково генерується унікальний номер картки від 1 до 1000;
- випадково генерується сума грошей від 1000 до 10000 грн;
- випадково обирається тип: економний, звичайний або марнотратний;
- генерується плановий бюджет;
- генерується реалістичний ліміт кошика від 1 до 15 одиниць товару.

### Два режими симуляції

1. Реалістичний режим — покупець купує не більше свого випадкового ліміту від 1 до 15 одиниць.
2. Режим за умовою практичного завдання — покупець продовжує покупки, доки в нього вистачає грошей хоча б на один наявний товар або доки товари не закінчаться.

Це дозволяє використовувати більш реалістичну модель для демонстрації, не втрачаючи можливості показати точну логіку початкової умови завдання.

### Додаткові можливості

- кошик покупця;
- консольний чек;
- категорії товарів;
- покупки від 1 до 3 одиниць за одну операцію;
- випадкові складські залишки до 250 одиниць;
- таблиця руху товарів;
- індикатори залишків;
- прибуток магазину;
- загальна кількість проданих одиниць;
- середній чек;
- найпопулярніший і найменш популярний товар;
- покупець із найбільшою кількістю товарів;
- покупець із найбільшими витратами;
- кольорове консольне оформлення та структуровані меню.

Для організації коду використано class Customer, class Store, struct Product, struct Purchase та enum CustomerType.

## Завдання 2 — соціальна мережа

У коді створено декілька користувачів. Кожен має ім'я, email, nickname та власні пости.

Кожен пост містить дату створення, текст, кількість лайків і коментарі.

Можливості програми:

- перегляд останніх 5 постів іншого користувача з повною інформацією;
- лайк поста іншого користувача;
- коментар до поста іншого користувача;
- створення власного поста;
- видалення власного поста;
- перегляд власних постів;
- зміна поточного користувача.

Для організації коду використано class User, class Post, class SocialNetwork та struct Comment.

Проєкт налаштований на .NET 11.0.
