# OOP-Lab4

Практичне завдання №4 з дисципліни «Об'єктно-орієнтоване програмування».

Тема: Структури, класи, функції.

## Завдання 1 — магазин

Симуляція магазину розширена, але базові вимоги практичного завдання збережені.

Програма:

- отримує кількість покупців з консолі (від 1 до 1000);
- створює для кожного унікальний випадковий номер картки від 1 до 1000;
- генерує стартову суму грошей від 1000 до 10000 грн;
- містить товари з назвою, категорією, ціною та кількістю;
- використовує три типи покупців: економний, звичайний та марнотратний;
- генерує орієнтовний плановий бюджет покупця;
- використовує бюджет для моделювання поведінки, але не як умову завершення: покупець продовжує купувати, доки має гроші хоча б на один наявний товар;
- дозволяє за одну операцію взяти від 1 до 3 одиниць товару;
- додає покупки до кошика;
- після кожного покупця формує консольний чек;
- після покупки зменшує залишок товару та гроші покупця;
- збільшує прибуток магазину на точну суму покупки;
- показує рух товарів: початкову кількість, продану кількість та залишок;
- виводить прибуток, кількість проданих одиниць і середній чек;
- визначає картку покупця з максимальною кількістю придбаних товарів;
- визначає картку покупця, який витратив найбільше грошей;
- визначає найпопулярніший та найменш популярний товар.

Для організації коду використано class Customer, class Store, struct Product, struct Purchase та enum CustomerType.

### Меню магазину

1 - Переглянути товари
2 - Запустити нову симуляцію покупців
3 - Переглянути рух товарів і залишки
4 - Переглянути статистику магазину
0 - Повернутися до головного меню

## Завдання 2 — соціальна мережа

У коді створено декілька користувачів. Кожен має ім'я, email, nickname та власні пости.

Кожен пост містить дату створення, текст, кількість лайків і коментарі.

Можливості програми:

- перегляд останніх 5 постів іншого користувача з повною інформацією;
- лайк поста іншого користувача;
- коментар до поста іншого користувача;
- створення власного поста;
- видалення власного поста;
- перегляд власних постів;
- зміна поточного користувача.

Для організації коду використано class User, class Post, class SocialNetwork та struct Comment.

## Запуск

Проєкт налаштований на .NET 11.0.

Виконайте команду: dotnet run

Головне меню:

1 - Симуляція покупців у магазині
2 - Симуляція соціальної мережі
0 - Вихід
