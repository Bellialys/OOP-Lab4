# OOP-Lab4 — ФІТ-2-15

Практичне завдання №4 з об'єктно-орієнтованого програмування на C#.

У застосунку є дві незалежні симуляції: магазин 🛒 та соціальна мережа 🌐. Інтерфейс — українською мовою. Застосунок працює локально, без бази даних, інтернету та сторонніх бібліотек.

## 1. Магазин 🛒

- 24 товари, категорії, ціни та випадкові залишки 40–250 одиниць.
- Сума на картці покупця 1000–10000 грн, унікальний номер картки 1–1000.
- Три типи поведінки: економний, звичайний, марнотратний.
- Кошик, чеки, візуальні індикатори складу, статистика прибутку й продажів.
- Два режими:
  1. Реалістичний — кожен покупець має випадковий ліміт 1–15 одиниць товару.
  2. За умовою завдання — покупець купує, поки має гроші на наявний товар або доки товари не закінчаться.

Ці режими розділені, щоб додаткове обмеження кошика не порушувало оригінальне завдання.

## 2. Соціальна мережа 🌐

Чотири демонстраційні користувачі з ім'ям, email, нікнеймом, аватаром і описом.

Можливості:

1. 📰 Персональна стрічка останніх дописів користувачів, на яких є підписка.
2. 🔍 Перегляд саме останніх п'яти дописів іншого користувача (за датою створення).
3. ❤️🔥😂👏 Реакції до чужих дописів; один користувач — одна реакція на допис.
4. 💬 Коментарі до чужих дописів із зазначенням автора і часу.
5. ✍️ Створення власних дописів до 280 символів, із підтримкою смайликів.
6. 🗑️ Видалення лише власних дописів з підтвердженням.
7. 👤 Перегляд власного профілю і всіх своїх дописів.
8. 👥 Перегляд інших користувачів, підписка і відписка.
9. 🔄 Перемикання між користувачами.
10. 🔥 ТОП-5 популярних дописів за кількістю вподобань.

Усі п'ять вихідних вимог до соціальної мережі збережені: дані користувача, характеристики допису, останні п'ять чужих дописів, лайк і коментар, створення та видалення свого допису. Додаткові можливості — необов'язкові покращення.

Реакції від демонстраційних користувачів додаються до початкової кількості вподобань у підготовлених дописах. Підписки, дописи, лайки й коментарі зберігаються у пам'яті до завершення роботи застосунку; після повторного запуску тестові дані відновлюються.

## Запуск

Потрібен .NET 11 SDK, який підтримує цільову платформу net11.0.

У терміналі каталогу проєкту:

    dotnet restore
    dotnet build
    dotnet run

## Вбудована самоперевірка 🧪

Без сторонніх тестових бібліотек:

    dotnet run -- --self-test

Перевірки охоплюють випадкові залишки, унікальні картки, ліміт 15 товарів, баланс грошей/товарів, академічний режим магазину, сортування дописів, унікальні реакції, коментарі, видалення, підписки й популярні дописи.

## Структура ООП

Класи: Customer, Store, User, Post, SocialNetwork.

Структури: Product, Purchase, Comment.

Перелік типів: CustomerType.

Виведення та перевірка вводу винесені до ConsoleUI та ConsoleHelper.

Демоелектронні адреси є вигаданими (example.com). Програма не працює з особистими даними справжніх користувачів.

## Примітка про відображення emoji

Для коректного показу Unicode та смайликів використовуйте Windows Terminal або сучасний термінал VS Code з підтримкою UTF-8 та шрифтом, який містить emoji. В окремих застарілих терміналах смайлики можуть виглядати як порожні квадрати.
