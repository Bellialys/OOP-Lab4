# OOP-Lab4

Практичне завдання №4 з дисципліни «Об'єктно-орієнтоване програмування».

Тема: Структури, класи, функції.

## Завдання 1 — магазин

Програма отримує кількість покупців з консолі (від 1 до 1000), генерує для кожного унікальний випадковий номер картки від 1 до 1000 та стартову суму від 1000 до 10000 грн.

Магазин містить набір товарів із назвою, ціною та кількістю. Покупки тривають, поки покупець може придбати хоча б один наявний товар. Після кожної покупки зменшується кількість товару та гроші покупця, а прибуток магазину збільшується.

Наприкінці виводиться прибуток магазину, картка покупця з найбільшою кількістю придбаних товарів та картка покупця, який витратив найбільше грошей.

Використано class Customer, class Store та struct Product.

## Завдання 2 — соціальна мережа

У коді створено декілька користувачів. Кожен має ім'я, email, nickname та власні пости.

Кожен пост містить дату створення, текст, кількість лайків і коментарі.

Можливості програми: перегляд останніх 5 постів іншого користувача з повною інформацією, лайк, коментар, створення власного поста, видалення власного поста, перегляд власних постів та зміна поточного користувача.

Використано class User, class Post, class SocialNetwork та struct Comment.

## Запуск

Проєкт налаштований на .NET 11.0.

Виконайте команду: dotnet run

Головне меню:
1 - Симуляція покупців у магазині
2 - Симуляція соціальної мережі
0 - Вихід
